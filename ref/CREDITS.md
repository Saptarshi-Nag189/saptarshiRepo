# Credits

LyricStage ports design ideas (template set, template chooser, LRC parsing and
word-timing estimates, playback clock smoothing, liquid glass background with
per-word ripples) from LyricalStudio. No web code is copied; concepts were
re-implemented in Kotlin and Jetpack Compose.

Clone the reference with:

    git clone https://github.com/arijit-debug/LyricalStudio ref/LyricalStudio
